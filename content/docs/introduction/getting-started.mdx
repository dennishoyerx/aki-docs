Aki docs is a small Fumadocs React Router site built with Vite, Bun, and TypeScript. The site documents Aki; it does not start the AKR runtime.

## Start the docs locally

Run this exact quickstart. Keep `bun run dev` running while you use the local site, and run the checks from another terminal when needed.

```bash
bun install
bun run dev
bun run typecheck
bun run build
bun run smoke
```

Open the URL printed by the development server. Search uses a local index built from `content/docs`; it does not call a hosted search service.

For a production-style local check, build first, then run `PORT=3000 bun run start` in another terminal and request the docs site's health route:

```bash
curl -i http://localhost:3000/health
```

That `/health` response belongs to `aki-docs`. It is not an AKR runtime health check, and the docs container does not start the runtime.

## Learn the request chain

Aki turns a request into a deliberate action and then resolves a versioned capability:

```text
request → Agent decides → Rev resolves → executor runs → result
                                      ↘ Ren presents kind=ui
                         Store supplies context-bound data
```

Read [Architecture](/docs/architecture) for ownership, then use [Runtime](/docs/runtime), [Extending](/docs/extending), and [Reference](/docs/reference) as needed. The [glossary](/docs/reference/glossary) is a compact vocabulary reference.
