This page is about the **Aki product**, not this documentation site. The product Compose file defines separate `akr` (Kernel/Gateway) and `aki` (web app) services, and the web app depends on the Gateway. The docs repository's `bun run ...` commands build or verify documentation only; they do not start AKR.

Choose the mode before running commands: **development Compose** gives you a mutable local loop; the **production release transaction** promotes immutable, SHA-identified images and is the only path that should be described as a release.

## Before starting

Run these commands from an Aki product checkout with its normal Compose prerequisites prepared by the operator. The public Compose file expects an environment file and operator-provided networks/volumes; this page does not reproduce their values or deployment details.

## Development start

For a local development loop, use the development overlay together with the base Compose file:

```sh
export AKI_DEPLOY_SHA="$(git rev-parse HEAD)"
docker compose -f compose.yml -f compose.dev.yml up --build
```

The development overlay deliberately keeps source/plugin mounts and development image names. It is convenient, mutable, and not an evidence-backed production release. The SHA variable is only a Compose interpolation requirement; the release rules below still require a clean, immutable release path.

## Production release

From a clean Aki checkout, use the product repository's deployment interface:

```sh
SOURCE_SHA="$(git rev-parse HEAD)"
AKI_DEPLOY_SHA="$SOURCE_SHA" ./scripts/deploy.sh plan kernel
AKI_DEPLOY_SHA="$SOURCE_SHA" ./scripts/deploy.sh apply kernel
AKI_DEPLOY_SHA="$SOURCE_SHA" ./scripts/deploy.sh verify kernel
```

Replace `kernel` with `web` for the other service scope, or use `all` for one combined transaction. `plan` is read-only. `apply` builds a candidate, captures the previous image, promotes the exact service scope, runs the evidence gates, and rolls back on failure. `verify` compares the running image ID and artifact with the candidate.

For a manual recovery, use the recorded release transaction:

```sh
./scripts/deploy.sh rollback "reason"
```

The rollback reuses the previously captured image ID; it does not rebuild from `latest`. The full invariant, gate, and rollback contract is documented under [Deployment strategy](/docs/reference/deployment). The bare `bun run smoke` checks source and content contracts; after starting the built docs server, the full public-surface check additionally uses `BASE_URL=http://localhost:3000 bun run smoke` to validate HTML, Markdown, search, and documentation MCP without starting AKR.

## Verify the local Gateway

The Compose file publishes no host ports. The Gateway binds inside the `akr` container, so run the health and tool probes from that container rather than assuming a host-local port:

```sh
docker compose exec akr curl http://127.0.0.1:18768/health
docker compose exec akr curl http://127.0.0.1:18768/tools
```

`/health` reports the AKR service snapshot, including plugin, Store, MCP, and event-storm summaries. `/tools` reports the currently exposed tool sets and schemas. Both routes are public at the Gateway boundary; other routes may require the operator-configured API key. Browser access is through the operator-configured Traefik route, not a host port. See [API first contact](/docs/reference/api-first-contact) and [Security and policy](/docs/reference/security).

Open the web app through the operator-configured route for the `aki` service. The documentation site's own `/health` and `/mcp` routes belong to `aki-docs` and are not product health checks.

## Stop the product

For a local checkout that you own, stop the development services with:

```sh
docker compose -f compose.yml -f compose.dev.yml down
```

Do not run `docker compose down` in a shared or live deployment; ask the operator to manage that environment. Production rollback belongs to `deploy.sh rollback`, not to an ad hoc Compose teardown. For a complete public documentation check, return to [Getting started](/docs/introduction/getting-started).
