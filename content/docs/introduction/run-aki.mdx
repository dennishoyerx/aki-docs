This page is about the **Aki product**, not this documentation site. The product Compose file defines separate `akr` (Kernel/Gateway) and `aki` (web app) services, and the web app depends on the Gateway. The docs repository's `bun run ...` commands build or verify documentation only; they do not start AKR.

## Before starting

Run these commands from an Aki product checkout with its normal Compose prerequisites prepared by the operator. The public Compose file expects an environment file and operator-provided networks/volumes; this page does not reproduce their values or deployment details.

## Start the product

```sh
docker compose up --build
```

This starts the product services described by the public `compose.yml`. It is separate from the docs-only `bun run smoke` check, which validates content, HTML, Markdown, search, and documentation MCP surfaces without starting a runtime.

## Verify the local Gateway

The Compose file publishes no host ports. The Gateway binds inside the `akr` container, so run the health and tool probes from that container rather than assuming a host-local port:

```sh
docker compose exec akr curl http://127.0.0.1:18768/health
docker compose exec akr curl http://127.0.0.1:18768/tools
```

`/health` reports the AKR service snapshot, including plugin, Store, MCP, and event-storm summaries. `/tools` reports the currently exposed tool sets and schemas. Both routes are public at the Gateway boundary; other routes may require the operator-configured API key. Browser access is through the operator-configured Traefik route, not a host port. See [API first contact](/docs/reference/api-first-contact) and [Security and policy](/docs/reference/security).

Open the web app through the operator-configured route for the `aki` service. The documentation site's own `/health` and `/mcp` routes belong to `aki-docs` and are not product health checks.

## Stop the product

For a local checkout that you own, stop the services with:

```sh
docker compose down
```

Do not run `docker compose down` in a shared or live deployment; ask the operator to manage that environment. Stopping the product does not change the docs-only commands. For a complete public documentation check, return to [Getting started](/docs/introduction/getting-started).
